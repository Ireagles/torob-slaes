# پایلوت: pending، اجرا نشده

پایلوت واقعی نیازمند مجوز جداگانه سایت زنده و دسترسی پایدار ۳ تا ۷ روز است. این نشست هیچ پایلوت چندروزه یا قیمت production ثبت نکرده است.

ورودی ضروری: ۲۰ تا ۳۰ محصول و لینک ترب تأییدشده، کیفیت و مدل دقیق، هویت خودی، واحد واقعی WooCommerce، نسخه‌های مقصد و فهرست نویسندگان قیمت؛ provider با observation time معتبر، seller identity و کیفیت offer کافی. قالب فعلی JSON-LD برای این هدف کافی نیست.

ابتدا staging: قیمت‌ها/واحد/sale/variation را با کنترل دستی مقایسه کنید؛ سپس production پایش/پیشنهاد و بعد از مجوز، فقط selected products با سقف کم، budget کافی و cron واقعی. توقف باید همیشه در دسترس باشد.

روزانه از CLI `wp vsp status`، صف Action Scheduler گروه افزونه، جدول usage و history خروجی بگیرید. معیارهای لازم: قیمت خارج حدود صفر؛ داده کهنه اعمال‌شده صفر؛ کیفیت اشتباه صفر؛ overwrite ویرایش دستی صفر؛ پوشش/سن واقعی، latency، retries، oldest job، خطا و هزینه واقعی. نتیجه نمایش ترب فقط با مشاهده بعدی واقعی ثبت شود.
