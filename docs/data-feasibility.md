# فاز صفر — امکان‌سنجی داده واقعی ترب

تاریخ: ۱۰ اکتبر ۲۰۲۶. محیط اولیه: مخزن خالی `torob-slaes`، بدون AGENTS.md، بدون PHP/WP/WC؛ هیچ کد قبلی جایگزین نشده است.

## نتیجه واقعی

اولین درخواست `https://torob.com/` با CONNECT 403 از **پراکسی محیط** مسدود شد. پس از ثبت دامنه‌های لازم در پیش‌نویس تنظیمات شبکه، همان دامنه HTTP 200 داد. بنابراین این رویداد شاهد CAPTCHA یا منع خود ترب نیست.

با یک جست‌وجوی عمومی باتری، لینک‌های واقعی کشف شدند؛ سپس robots.txt بررسی شد: `/search/` برای crawler ممنوع است. جست‌وجوی برنامه‌ریزی‌شده/کشف لینک خودکار پیاده نشده و تکرار نشد؛ adapter فقط لینک محصول `/p/<UUID>/...` تأییدشده مدیر را درخواست می‌کند. مجاز بودن فنی robots به‌تنهایی قرارداد تجاری یا مجوز API نیست؛ هیچ endpoint خصوصی یا redirect خرید درخواست نشد.

سه صفحه عمومی محصول HTTP 200 و JSON-LD واقعی شامل شش offer دادند. parser واقعی برای همین قالب ساخته شد. خروجی به‌وضوح **واقعی، ولی نامعتبر برای اعمال قیمت** است: زمان مشاهده قیمت وجود ندارد؛ `priceValidUntil` زمان مشاهده نیست؛ تاریخ تغییر قیمت در متن نیز تضمین زمان آخرین بررسی منبع نیست. کیفیت هر offer و دامنه/store ID معتبر در JSON-LD موجود نیست. هیچ‌یک از این مقادیر از زمان fetch، عنوان کالا یا نام فروشنده حدس زده نشده‌اند.

| canonical ID / مدل | آنچه واقعاً دریافت شد | مشکل تطبیق / پوشش |
|---|---|---|
| `1189b812-9de1-4016-b72d-fa7d3292ff9b` / Mi 10T Lite | شش offer با IRR؛ نمونه البرز دکه 26,413,700 ریال | توضیح کلی صفحه از Mi 10 نام می‌برد؛ کیفیت هر offer احراز نشده. کمترین selected JSON-LD با lowPrice کلی برابر نیست. |
| `fdfc2e3f-aa9f-4797-95e5-41d6bedc55d0` / Nokia 106 BL-5C | شش offer؛ نمونه مای باتری 1,980,000 ریال | دامنه خودی و زمان مشاهده نامعلوم؛ یک نام فروشنده برای دو offer دیده شد. |
| `7ebe9885-1977-453e-b80f-64935bf1bdc6` / Poco M3 | شش offer؛ نمونه پیت شاپ 12,790,000 ریال | کیفیت و تمام فروشندگان احراز نشده؛ highPrice کلی از selected offers بیشتر است. |

پاسخ HTML در این محیط نزدیک انتهای `__NEXT_DATA__` ناقص بود؛ کد به آن برای ادعای دریافت تمام فروشندگان وابسته نیست. JSON-LD کامل، schema آن اعتبارسنجی و URLهای tracking/شناسه‌های نشست حذف شدند. fixture پاک‌سازی‌شده برای **بازپخش آزمون** است، نه داده جاری و نه شاهد تازگی.

## محدودیت PHP در این محیط

درخواست Python با پراکسی محیط قیمت واقعی دریافت کرد. ولی `wp_safe_remote_get` با `A valid URL was not provided` متوقف شد؛ `gethostbyname('torob.com')` در این container نام را بدون IP برمی‌گرداند. این مانع DNS/HTTP امن WordPress است. SSRF/TLS برای حل آن غیرفعال نشده‌اند. آزمون اتصال PHP تولید در هاست مقصد تا داشتن DNS واقعی یا مسیر پراکسی پشتیبانی‌شده **blocked** است؛ آزمون parser روی پاسخ واقعی و آزمون transport با شبیه‌سازی جدا گزارش شده‌اند.

## اطلاعات هنوز ناموجود

۲۰ تا ۳۰ لینک منتخب واقعی با کیفیت مشخص، هویت و دامنه ویراتل، واحد و نسخه‌های سایت مقصد و افزونه‌های تغییردهنده قیمت از کاربر درخواست شده‌اند. نمونه‌های بالا جای نمونه پذیرش فروشگاه نیستند. بدون هویت خودی یا کیفیت معتبر، موتور fail-closed است.

برای منبع خودکار لازم است یک مسیر مجاز، زمان observation معتبر، پوشش کافی، هویت فروشنده و ویژگی‌های offer را فراهم کند. API عمومی رسمی ترب فرض نشده است؛ Worker نیز بدون دلیل/مجوز سرویس پیاده‌شده محسوب نمی‌شود. هیچ قیمت production تغییر نکرده است.

## نرخ و هزینه

نظری: ۲۰۰۰ × ۴ × ۳۰ = ۲۴۰٬۰۰۰ بررسی/ماه، ۸۰۰۰/روز، حدود ۵٫۵۶/دقیقه. با اشتراک ۱۰ محصول در هر canonical، بدون retry حدود ۸۰۰ fetch/روز می‌شود؛ فقط وقتی این اشتراک واقعی و کیفیت مستقل معتبر باشد. تنظیم محافظه‌کارانه نسخه: حداقل ۱۰ ثانیه بین درخواست‌ها، بودجه ۱۰۰/روز و ۳۰۰۰/ماه، گروه عادی هر ۶ ساعت؛ مدیر باید نرخ را مطابق سیاست منبع و پایلوت انتخاب کند. سرآیند محدودیت نرخ مشاهده‌شده تضمین ظرفیت/حق مصرف نیست. هزینه پولی منبع و billable units نامعلوم است؛ صفر فرض نمی‌شود.

این نشست، آزمایش چندروزه نیست. خروج فاز صفر: مسیر پایش خواندنی واقعی پیدا شد؛ **مسیر خودکار تولید به‌دلیل نقص داده و آزمون PHP مقصد مسدود است**.
