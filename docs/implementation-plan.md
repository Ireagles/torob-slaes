# برنامه اجرا

مخزن اولیه خالی و بدون AGENTS.md است. تغییر production در محدوده کار نیست.

۰. محیط و اتصال خواندنی ترب؛ مانع شبکه از مشکل منبع تفکیک شود.
۱. bootstrap، schema نسخه‌دار، capability و نصب پایش.
۲. موتور قطعی مستقل با integer minor units و آزمون قواعد/کیفیت.
۳. adapter منبع بدون جعل موفقیت، snapshot/usage و پایش محدود.
۴. پیشنهاد نسخه‌دار، WooCommerce CRUD، intent، lock، recovery و rollback.
۵. CSV پیش‌نمایش/اعمال chunk، Action Scheduler، CLI و benchmark آزمایشی.
۶. برنامه و runner پایلوت ۳–۷ روز؛ اجرای واقعی pending تا داشتن ورودی و مجوز مستقل تولید.
۷. تکمیل P1 و rollout مرحله‌ای پس از شواهد پایلوت.
۸. adapterهای P2 فقط پس از پایداری هسته و با API/account واقعی.

تحویل مشترک فازهای توسعه: بازبینی، راهنمای فارسی، گزارش شواهد و ZIP تک‌ریشه. ترتیب فازها به بخش ۱۶ بریف اشاره دارد؛ وضعیت واقعی هر معیار در implementation-status ثبت می‌شود.

فرضیات: یک واحد داخلی برابر یک‌صدم ریال است؛ واحد ووکامرس باید صریح IRT/IRR باشد. کیفیت و مدل دقیق اجباری؛ sale پیشفرض تعارض است. منبع احرازنشده اجازه تغییر قیمت ندارد. آزمون محلی از داده آزمایشی جداگانه استفاده می‌کند. برای WP/WC فقط نسخه‌های واقعاً آزموده‌شده گزارش می‌شوند. پایلوت ۳ تا ۷ روز و اتصال‌های P2 اجراشده محسوب نمی‌شوند.
